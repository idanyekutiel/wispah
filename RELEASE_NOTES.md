## Installation

1. Download the DMG below
2. Open it and drag Wispah to Applications
3. Launch Wispah Flow and follow the setup wizard

## Changelog

- **Post-processing master toggle** — enable/disable all post-processing with one switch, without losing individual settings
- **Custom post-processing instructions** — add your own rules (e.g. "remove filler words like 'so like'", "keep sentences short") to fine-tune how transcriptions are cleaned up
- **Tab reorder** — Stats, Dictionary, Transcriptions, Settings (sidebar + menu bar)
- **Settings page reorganized** — logical sections with headers (Recording, Transcription, Data & Privacy)
- **TextEditor padding** — dictionary and custom instructions fields no longer cramped against borders

## Requirements

- macOS 13.0 or later
- Microphone permission
- Accessibility permission
- Screen Recording permission (optional)
- Free Groq API key ([get one here](https://console.groq.com/keys))
